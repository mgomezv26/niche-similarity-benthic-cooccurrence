# 03 — Procesamiento espacial

**Idioma: [English](README.md) | Español**

Esta etapa documenta los procedimientos espaciales utilizados para preparar la cuadrícula marina global y asociar la información ambiental y las ocurrencias de especies a las unidades espaciales.

| Script | Finalidad |
|---|---|
| `03_01_create_ocean_grid.py` | Creación de la cuadrícula espacial oceánica |
| `03_02_assign_meow_realms.R` | Asignación de regiones marinas MEOW a las celdas |
| `03_03_extract_environmental.R` | Extracción de información ambiental para las unidades espaciales |
| `03_04_assign_species_to_grid.R` | Asignación de registros de ocurrencia de especies a las celdas |

Algunos procedimientos espaciales se apoyaron en operaciones externas de SIG. Los scripts documentan los procedimientos originales y no deben interpretarse como un flujo completamente automatizado.
