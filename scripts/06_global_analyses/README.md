# 06 — Global analyses

**Language: [English](README.md) | [Español](README.es.md)**

This folder contains the scripts for the global-scale co-occurrence analysis, its relationship with environmental niche similarity/proximity, and the subsequent evaluation of residuals against COI genetic distances for **Cnidaria** and **Porifera**.

## Scripts and workflow

| Script | Main inputs | Results |
| --- | --- | --- |
| `06_01_calculate_global_cooccurrence.R` | `data/processed/grids/species_grid_assignments.gpkg` | Absolute co-occurrence matrix, spatial Jaccard distance, and cell counts per species (`results/global_analyses/cooccurrence/`). |
| `06_02_mantel_tests_and_residuals.Rmd` | Hypervolume overlap (`results/hypervolumes/overlap/`), Schoener's D (`results/hypervolumes/schoener/`), and spatial Jaccard distance from step 06_01 | Matrices aligned by species, three global Mantel tests, residuals, diagnostic tables, and figures (`results/global_analyses/mantel/`). |
| `06_03_cnidaria_phylogenetic_residuals.Rmd` | Global Schoener and Jaccard residuals, species order, taxonomic mappings, and external Cnidaria COI matrix | Two residual–genetic distance Mantel tests, filtered residuals, and figures (`results/global_analyses/phylogenetic_residuals/cnidaria/`). |
| `06_04_porifera_phylogenetic_residuals.Rmd` | Global Schoener and Jaccard residuals, species order, taxonomic mappings, and external Porifera COI matrix | Two residual–genetic distance Mantel tests, filtered residuals, and figures (`results/global_analyses/phylogenetic_residuals/porifera/`). |

**Execution order:** `06_01` → `06_02` → `06_03` and `06_04` (the last two are independent of each other). The hypervolume scripts in `05_hypervolumes/` must have been run before `06_02`.

## External inputs for the COI analyses

- `data/raw/phylogenetics/cnidaria/Cnidaria_Distance_Matrix_COI_MEGA.xlsx`
- `data/raw/phylogenetics/porifera/Porifera_Distance_Matrix_COI_MEGA.xlsx`
- `data/interim/phylogenetics/species_hv_names_tax.xlsx` (`Cnidaria` and `Porifera` sheets).
- `results/global_analyses/mantel/species_order.csv`, `mantel_residuals_schoener.rds`, and `mantel_residuals_jaccard.rds`, generated by `06_02`.

The **COI distance matrices were obtained through an external analysis using specialized software**. These Rmd documents **neither generate nor validate the original genetic distances**: they import the received matrices, associate them with species, and evaluate their relationship with the global residuals. The former `17_Phylogeny.R` is not considered a substantiated generator of the final COI matrices.

## Criteria and reproducibility

- In `06_01`, each species–cell combination is counted only once, and the filter requiring presence in at least **10 cells** is retained.
- `06_02` performs **three Mantel tests** (Pearson, **1,000 permutations**) and obtains the global residuals used by the subsequent Rmd documents.
- `06_03` and `06_04` perform **two Mantel tests per phylum** (Pearson, **999 permutations**), comparing COI distances with Schoener and Jaccard residuals.
- The reorganized versions use relative paths through `here()` and set `set.seed(123)` for the Mantel tests. **P-values may differ** from the historical HTML documents, where the seed was not set in the same way.
- All three Rmd documents retain calculations and figures together; there are no duplicate code copies in `08_figures/`.
- **Status:** reorganized scripts, without end-to-end execution or verification of numerical equivalence with historical results. The original HTML documents must be retained as a reference during validation.

Large datasets and historical results are currently kept outside GitHub; data publication and versioning will be decided separately.
